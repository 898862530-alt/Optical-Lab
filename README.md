# 光场 · 相机虚化实验室 v0.2

本地单照片虚化模拟 demo。启动后访问 http://127.0.0.1:8765 。

## 启动

本机依赖与模型已安装。双击 `start.command`，或在本目录运行 `.venv/bin/python app.py`。保持启动终端开启；已运行时无需重复启动。升级后刷新页面并重新上传照片。

新环境使用 Python 3.9+，执行 `bash setup.sh` 安装依赖与约 1.34 GB 的 Depth Anything V2 Large FP32 模型，再运行 `./start.command`。安装需联网；安装后推理与渲染均在本机，无外部照片上传。

## 使用

1. 上传 JPEG / PNG / WebP / TIFF（最多 100 MB、6000 万像素）。当前支持 8 位照片；16 位输入会明确提示，避免静默降位深。HEIC / RAW 请先转换。
2. 等待 Large 高精度分析，界面显示模型加载、三次推理、融合的阶段进度。性能以精度优先，可能需要数分钟。
3. 查看相对深度图，核实原图光圈、焦距、传感器尺寸；填入场景最近/最远距离，并点击原片实际对焦位置。
4. 选择目标设备并计算预览。目标传感器面积及裁切后有效画幅不得小于原图，光圈 f 值不得大于原图；允许相等作对照。
5. 点击「原尺寸导出 PNG」，程序在原图完整像素上重新渲染，显示分块处理进度，导出宽高与方向校正后的原图一致。
6. 「导出 16 位深度图」输出原尺寸相对逆深度 PNG（亮近暗远，0–65535）；它不是米制测距结果。

## 此版本的两项改进

### 高精度深度

- Small（约 24.8M 参数）更换为 Large（约 335M 参数）的 FP32 模型。
- 原图独立保留，模型直接读取原图，而非 1200 像素预览。
- 使用接近官方的等比例、14 倍数尺寸预处理；移除上一版「最长边 518、方形补边」的限制。
- 三次推理：短边 518、短边 1008、短边 1008 水平镜像。受本机 16 GB 内存限制，每次输入上限约 145 万像素；非常宽或高的照片会等比例下调推理尺寸。实际输入尺寸直接显示在页面中。
- 对相对逆深度做正仿射尺度对齐，融合高分辨率与镜像预测，低分辨率结果仅以低频方式补充全局布局。
- 深度主场最长边最多 2048，保留 float32；以受限的引导滤波系数和原图亮度重建原尺寸边缘，减轻上采样跨边缘混合。颜色边缘不保证等于真实几何边缘，因此仅使用 30% 引导结果，保留模型预测为主。
- 归一化使用 0.1% / 99.9% 分位，减轻极值压缩。导出 16 位深度图的量化仅发生于输出，虚化内部始终使用 float32。

**原尺寸深度是高分辨率模型预测加边缘引导重建，不代表网络对每个原始像素进行了独立测距。** 单目深度仍可能误判透明物、反射、细线与已有重度散焦区域。目前没有已知真值深度数据，因此不能给出本项目的绝对深度误差改善百分比。

### 原尺寸导出

- 完整 RGB 与透明度（存在时）保存在本机内存中；仅界面预览缩到最长边 1200。
- 导出直接处理原图像素，不放大预览；模糊半径根据完整输出尺寸重新计算。
- 640 像素分块渲染，重叠区覆盖最大散焦半径；所有块使用同一焦点、层划分和光斑半径，避免块边界接缝。
- 使用 64–256 个深度层，随模糊半径调整，较旧版固定 40 层更细。
- PNG 保留原尺寸，不使用有损压缩。输入的有效 ICC 配置转换为 sRGB，输出嵌入 sRGB 配置；像素虚化为 8 位 RGB。透明度通道保持原始尺寸与取值。导出不携带旧相机拍摄 EXIF，以免误表示模拟图的真实拍摄设备。
- **原尺寸 + PNG 不等于可逆的无损编辑**：虚化会改变像素，颜色空间转换也可能改变像素。对于原本为 sRGB 的输入，当原/目标参数完全相同时，渲染保持输入解码后 RGB 像素不变。

上传图不落盘，内存最多保留最近 2 张照片；完成的导出最多保留 3 份。退出服务后清除。分析和原尺寸导出串行排队，避免多次大模型推理同时占满内存。

## 光学与适用范围

仅凭单张 RGB、光圈和传感器面积，无法唯一确定真实光学虚化；仍需实际焦距、原始焦点、绝对距离、裁切信息及原镜头点扩散函数。被遮挡颜色、饱和高光辐射量无法恢复。

假定薄透镜、圆形光瞳、相同机位、相同构图与相同焦平面。先按照片比例计算传感器有效对角线 d。距离、焦距均为毫米，q 是归一化相对逆深度：

- `1/z = 1/z_far + q × (1/z_near − 1/z_far)`，距离为用户校准假设。
- 焦点 q 取点击处原尺寸 5×5 中位数，在预览和导出间一致。
- `k = d_target/d_source`。
- 有限距离下匹配焦平面放大率：`f_target = k f_source s / [s + (k−1) f_source]`。
- 传感器弥散圆直径：`c(z) = f² |z−s| / [N z (s−f)]`。
- 像素弥散圆：`c_px = c × image_diagonal_px / sensor_active_diagonal_mm`。
- 增量半径：`r = 0.5 sqrt(max(c_target_px² − c_source_px², 0))`。

增量半径为匹配圆盘核二阶矩的方差近似，不是精确反卷积。渲染采用线性光、分层圆盘散射、预乘 alpha 远到近合成。没有真实的隐藏背景；已有重度虚化、发丝、透明物仍会存在误差。不模拟口径蚀、猫眼、球差、衍射、镜头呼吸和特定镜头叶片。

## EXIF

读取 FNumber / ApertureValue、FocalLength、FocalLengthIn35mmFilm、SubjectDistance 与相机名称。EXIF 通常没有可靠的物理传感器面积；若有实际与等效焦距，按 `d=43.2666×f/f35` 推算，明确标记假定 3:2。裁切、防抖、多摄融合可能导致推算失准。没有依据时使用待核实默认值。

## 验证

`.venv/bin/python -m unittest discover -s tests -v`

测试包括光学不变量、非法参数、EXIF、原尺寸与方向、像素级零增量对照、浮点深度、仿射对齐、分块与整图一致性、PNG 和 16 位深度导出。API 分辨率测试使用受控深度场隔离验证尺寸与像素保持，不将它当作模型精度测试。

2026-10-19：22 项测试通过。Large 模型真实运行一张 960×686 公开测试照片：三次输入为 728×518、1414×1008、1414×1008，CPU 实测约 148 秒，进程峰值约 5.0 GB（单次观测）。视觉检查相比旧模型能分辨更多轮廓与胡须细线；没有真值数据，无法推断米制误差。
